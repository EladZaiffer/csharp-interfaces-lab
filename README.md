# csharp-ממשקים

פרויקט Console ב-.NET 9 לתלמיד. כל המחלקות הקיימות ממומשות; רק המחלקה Drone נשארת בכותרת `public class Drone` ובגוף ריק.

פתחו את `InterfacesVideo.sln` ב-Visual Studio. שלוש המשימות נמצאות בקובץ `InterfacesVideo/Questions.cs`, בתוך הערות `/* ... */` ממוספרות. [הוראות התרגול ב-PDF](InterfacesVideo/Instructions/Drone-Questions.pdf) נמצאות בתיקיית Instructions בתוך הפרויקט.

1. ממשו את Drone, ההורשה, שתי היכולות, התכונות ופעולות הטיסה והטעינה.
2. שלבו אותו אובייקט בשני מערכי הממשקים ואמתו טעינה ואחריה טיסה.
3. הרחיבו בעצמכם את IChargeable באמצעות `string ChargingStatus();`, ראו אילו מחלקות אינן מקיימות עוד את החוזה, ותקנו את כולן. ספי הסוללה שונים לפי המכשיר והם מפורטים בשאלה וב-PDF.

חתימת ChargingStatus עדיין אינה בממשק שבשלד: הוספתה היא חלק ממשימה 3, כדי שהתלמיד יוכל לראות כיצד שינוי החוזה יוצר שגיאות בנייה. המחלקה Drone נשארת ריקה. לכל משימה יש נקודת התחלה ברורה בפרויקט.

אפשר להריץ גם משורת הפקודה, מתוך תיקיית החבילה:

```bash
dotnet run --project InterfacesVideo/InterfacesVideo.csproj
```

הפרויקט כולל IFlyable ו-IChargeable, את משפחות Animal, Vehicle, SuperHero, Device ו-Appliance, ואת Bird, Penguin, Airplane, Car, GasolineCar, Superman, Batman, ElectricCar, Phone ו-RobotVacuum. FlyingThing מופיעה רק כחלק מהדוגמה השגויה מהסרטון, והיא אינה בסיס נוסף למטוס.

פעולות Fly ו-Charge, מערכי הממשקים, מערך object, בדיקת is, בדיקה עם משתנה, והמרת as עם בדיקת null נכללים. לולאות ההפעלה נארזו בפעולות FlyAll ו-ChargeAll כדי שהתרגול יוכל לבדוק הוספת סוג בלי שינוי גוף הפעולה. אלה שמות פעולות עזר לתרגול.

Bird.Fly ו-Phone.Charge שומרות את ההדפסות שאומתו בסרטון. גופי ההדגמה של הסוגים האחרים הושלמו בהודעות לצורך תוכנית מלאה. סדר ההרצה טוען את המכשירים לפני הפעלת התעופה, כדי להתאים לרחפן שדורש טעינה. זו הדמיה באמצעות אחוז סוללה והדפסות, ללא חיבור לחומרה.

קובץ Questions.cs אינו כולל פתרון ל-Drone או קוד היוצר אותו. הפרויקט נועד לפעול גם לפני פתרון המשימות: הרחפן הריק עדיין אינו בשום מערך. שימו לב להוספת פסיקים למערכים כשמצרפים את הרחפן.

המקור: סרטון הממשקים C# dotnet.
